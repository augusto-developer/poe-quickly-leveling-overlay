Options

Game folder

Where Path of Exile is installed. The overlay only reads the log the game keeps there (logs\Client.txt), to know which area you are in.

Hotkeys

Click a key, then press the one you want. Esc cancels. Changes apply right away.

Back to F2, F3, F4 and P, with the tree search on? Your regex is kept.

My regex

A search you use often, for gear or anything else. The "Paste my regex" hotkey types it into the search field of the open window, such as a vendor or the stash.
